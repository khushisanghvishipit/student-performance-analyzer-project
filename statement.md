# Project Statement

## Project Title
Student Performance Analyzer and Scholarship Management System

## Problem Statement
Managing student marks and preparing performance reports manually can take time and may lead to calculation errors. Students and educators need a simple system to record marks, calculate academic performance, and check scholarship eligibility.

## Project Objectives
- Record student details and marks.
- Calculate total marks and percentage.
- Assign a grade and pass/fail status.
- Identify the highest-scoring subject.
- Check scholarship eligibility.
- Save and retrieve student records.

## Scope
The project is a Python-based, menu-driven application. It handles student details, marks for four subjects, performance calculations, scholarship eligibility, and local JSON storage. It is intended as a small academic project and does not include online accounts or a web interface.

## Target Users
- Students who want to review their academic performance.
- Teachers or academic staff who need to record and view student results.

## High-Level Features
1. Add student information.
2. Enter marks and generate a performance report.
3. Check scholarship eligibility.
4. Save student records in a JSON file.
5. View saved records and search by roll number.
