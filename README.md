# Student Performance Analyzer

## Project Description
The Student Performance Analyzer is a Python-based project that collects student details and subject marks, then generates a performance report.

## Features
- Enter student name, roll number, and course.
- Enter marks for four subjects.
- Calculate total marks and percentage.
- Assign a grade and show pass/fail status.
- Identify the highest-scoring subject.
- Check scholarship eligibility.
- Use a menu to add a student report or exit.

## Technologies Used
- Python
- VS Code

## Project Files
- `main.py` — Runs the main menu and displays the final report.
- `student.py` — Collects student details.
- `marks.py` — Calculates performance.
- `scholarship.py` — Checks scholarship eligibility.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `main.py` using Python.
4. Follow the on-screen prompts.
